# Terraform Labs

A hands-on Terraform learning repository documenting my journey from Infrastructure as Code (IaC) fundamentals to deploying production-style cloud infrastructure on AWS.

This repository is part of my Cloud Engineering learning path and contains progressively structured labs covering Terraform core concepts, AWS infrastructure provisioning, and Infrastructure as Code best practices.

---

## 📖 About

Terraform is an Infrastructure as Code (IaC) tool developed by HashiCorp that allows infrastructure to be defined, deployed, and managed using code.

This repository follows a lab-based approach where each lab introduces a new Terraform concept before applying it to real cloud infrastructure.

---

## 🎯 Learning Objectives

By completing these labs, I aim to:

- Understand Infrastructure as Code (IaC)
- Master Terraform fundamentals
- Provision AWS infrastructure using Terraform
- Build reusable Terraform modules
- Manage Terraform state effectively
- Follow Infrastructure as Code best practices
- Develop production-ready Terraform projects
- Build a professional cloud engineering portfolio
