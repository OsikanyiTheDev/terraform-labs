# Terraform Lab 1 - Installation & Setup

## Objective
The objective of this lab is to install Terraform, understand Infrastructure as Code (IaC), and set up the working environment for Terraform projects.

---

## Tools Installed
- Terraform v1.15.6
- Git
- Ubuntu Linux (VMware environment)

---

## Key Concepts Learned
- What Infrastructure as Code (IaC) means
- What Terraform is used for
- Terraform workflow:
  init → plan → apply → destroy
- Basic Terraform architecture:
  Provider, Resource, State
