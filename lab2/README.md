# Terraform Lab 2 - First Terraform Resource

## Objective
Learn Terraform basics by creating a local file using Infrastructure as Code.

## What I Built
- A local file using Terraform (`hello.txt`)

## Key Concepts
- Terraform providers
- Resources
- HCL syntax
- Terraform workflow (init, plan, apply, destroy)

## Commands Used
```bash
terraform init
terraform plan
terraform apply
terraform destroy
```
